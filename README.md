# Ostunimekiri

## Projekti autorid

- Sofja Gubatšjova
- Azhar Ryskhan

## Projekti kirjeldus

Ostunimekiri on C# ja WPF rakendus, mis aitab kasutajal hallata koduseid toiduvarusid ja koostada ostunimekirja.

Rakendus on mõeldud inimestele, kes soovivad paremini planeerida oma oste ja vältida toidu raiskamist.

## Põhifunktsioonid

- Toodete lisamine ja kustutamine.
- Koduste toiduvarude haldamine.
- Toodete koguse ja ühiku määramine.
- Ostunimekirja koostamine.
- Toodete ostetuks märkimine.
